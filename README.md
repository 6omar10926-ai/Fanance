# مالي — تطبيق إدارة الماليات الشخصية

تطبيق ويب لإدارة ماليتك الشخصية بواجهة عربية (RTL)، يشمل:

- **لوحة تحكم**: إحصائيات ورسوم بيانية (الدخل مقابل المصروفات، توزيع المصروفات حسب الفئة، تخصيص الاستثمارات) ونسب مالية رئيسية (معدل الادخار، نسبة المصروفات إلى الدخل، نسبة الاستثمار، عائد الاستثمار).
- **المصروفات**: تسجيل المصروفات اليومية مع تصنيفها حسب الفئة (طعام، مواصلات، سكن، فواتير...).
- **الاستثمارات**: تتبع محفظة استثمارية (أسهم، صناديق، عقار، ذهب، عملات رقمية، ودائع) مع حساب الأرباح ونسبة العائد.
- **الدخل**: تسجيل مصادر الدخل الشهرية والسنوية والمرة الواحدة، مع احتساب الدخل الشهري الثابت والسنوي المتوقع.
- **تحديات الدخل**: حدّد هدفاً لدخلك من مصدر معيّن خلال مدة (مثل: ١٠٬٠٠٠ ريال من العقار)، وسجّل كل مبلغ يصلك في التحدي لتتابع نسبة الإنجاز والمبلغ المتبقي والعدّ التنازلي حتى تُقفل الهدف.
- **المدفوعات**: متابعة الفواتير والالتزامات المالية مع حالتها (مستحقة، مدفوعة، متأخرة) ودعم الدفعات المتكررة.

تسجيل الدخول بالبريد الإلكتروني وكلمة المرور، وبياناتك تُخزَّن في Firestore ومرتبطة بحسابك، فتصلك من أي جهاز.

## التقنيات

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Recharts للرسوم البيانية
- React Router
- Firebase (Authentication + Firestore)

## إعداد Firebase (مطلوب قبل أول تشغيل)

1. أنشئ مشروعاً على [Firebase Console](https://console.firebase.google.com).
2. فعّل **Authentication → Email/Password**.
3. أنشئ **Firestore Database**.
4. أضف تطبيق ويب من إعدادات المشروع وانسخ كائن `firebaseConfig`.
5. ألصقه في `src/lib/firebase.ts` بدلاً من قيم `REPLACE_ME`.
6. في **Firestore → Rules** استخدم:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```
